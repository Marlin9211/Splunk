Debrief · 3 minutes
Your operating model

 

  
Lookups
External context becomes useful when Splunk can match a shared field. A lookup definition names and points to the lookup table; lookup enriches events, inputlookup reads a lookup table, and outputlookup writes supported search results to a static lookup/KV store. Automatic lookups apply at search time without manual invocation.

  
Alerts
An alert combines a saved search, timing/type, trigger condition and action. Scheduled alerts check on a schedule; real-time alerts monitor continuously. Throttling suppresses subsequent alerts for a defined period.

  
Triggered Alerts
Triggered Alert records appear when the action is enabled, the alert has triggered recently, retention has not expired, and the listing has not been deleted. Viewing results provides a starting point for troubleshooting.

  
Report ≠ Alert
A scheduled report performs its action whenever it completes. A scheduled alert performs its action only when its trigger condition is met.
